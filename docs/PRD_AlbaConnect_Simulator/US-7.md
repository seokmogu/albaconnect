# US-7: 사용자는 9,950명 규모 구직자를 탐색하기 위해 페이지네이션과 카테고리 필터를 사용할 수 있다

**Epic**: Epic 2 - 관제 대시보드

**Phase**: Phase 2

**Priority**: P1

**구현 상태**: 구현 완료 (`/sim/worker` 목록)

---

## 배경 및 해결하고자 하는 문제

구직자는 9,950명 규모다. 목록을 한 번에 렌더하면 브라우저가 멈춰 탐색 자체가 불가능하다. 운영자나 진입점 사용자가 특정 워커를 찾으려면 분할 표시와 필터가 필요하다.

---

## 기능 요구사항 (Functional Requirements)

### 세부 기능

**1. 페이지네이션**
구직자 목록을 페이지당 60명으로 분할하고, 페이지 이동 네비게이션을 제공한다.

**2. 카테고리 필터**
카테고리(cafe/restaurant/retail 등)별로 목록을 필터링한다.

**3. 카드 진입**
각 워커 카드를 클릭하면 해당 워커 상세/마이페이지로 이동한다.

---

## 상세 시나리오 (Detailed Scenarios)

### 시나리오 1: 정상 플로우 (Happy Path)

1. 사용자가 구직자 목록에 진입하면 1페이지(60명)가 표시된다.
2. 페이지 네비게이션으로 다음 페이지로 이동한다.
3. 카테고리 필터를 누르면 해당 카테고리 워커만 표시된다.

### 시나리오 2: 엣지 케이스 (Edge Cases)

* 필터 결과 0명: "해당 카테고리 워커 없음" 안내.
* 범위 밖 페이지 번호: 마지막 페이지로 보정.

---

## Acceptance Criteria

- [ ] 구직자 목록이 페이지당 60명으로 분할된다
- [ ] 페이지 네비게이션으로 페이지를 이동할 수 있다
- [ ] 카테고리 필터로 목록을 필터링할 수 있다
- [ ] 범위 밖 페이지 번호는 유효 범위로 보정된다
- [ ] 목록 첫 렌더가 1초 이내다

---

## 성공 지표 (Success Metrics)

* 목록 페이지 렌더 1초 이내
* 9,950명 전체 탐색 가능 (브라우저 멈춤 없음)

---

## 의존성 및 제약사항

* **선행**: 구직자 시드 데이터
* **제약**: 페이지 크기 60명은 조정 가능
