# US-15: 개인은 비전문 일상 잡무를 맡기기 위해 용역 의뢰를 등록할 수 있다

**Epic**: Epic 6 - 개인 용역 (C2C)

**Phase**: Phase 2

**Priority**: P0

**구현 상태**: 구현 완료 (용역 의뢰 목록 + 카테고리 필터 + 도급 안내)

---

## 배경 및 해결하고자 하는 문제

현재 알바몬 커넥트는 `사업주(Employer) ↔ 워커(Worker)` 단일 축이다. 의뢰 주체가 사업자등록을 가진 사업장으로 한정돼 있어, **개인이 개인에게 일을 맡기는 C2C 용역**이 통째로 빠져 있다.

세상의 노동수요는 사업장 알바만이 아니다 — 청소, 정리, 짐 옮기기, 가구 조립, 줄서기, 반려동물 산책처럼 **개인이 사업자등록 없이 다른 개인에게 맡기는 비전문 일상 잡무**가 거대한 시장이다 (당근알바가 증명). 알바몬 데이터레이크로는 이 수요가 보이지 않는다 (`GTM_Strategy.md` §0 — 2층 시장).

이 영역은 규제 안전지대이기도 하다: 일회성·비종속이라 근로기준법 밖(도급), 비전문이라 자격·면허 무관, 개인 간이라 사업자 규제 무관.

이 스토리는 개인이 비전문 용역을 의뢰하는 트랙을 추가한다.

---

## 기능 요구사항 (Functional Requirements)

### 세부 기능

**1. 개인 의뢰자**
사업자등록 없는 개인이 의뢰자가 될 수 있다. 의뢰자 유형은 `개인(individual)` 또는 `사업주(business)`.

**2. 용역 의뢰 등록**
의뢰자는 일상 잡무 의뢰를 등록한다 — 일의 내용(결과물 단위), 희망 시각, 위치, 보수.

**3. 계약 유형 = 도급(용역)**
용역 의뢰의 계약은 근로계약이 아니라 **도급계약**이다. 시급이 아니라 건당 보수가 기본.

**4. 비전문 카테고리**
errand(심부름), cleaning(청소), assembly(조립), moving(짐 옮기기), pet(반려동물), queue(줄서기) 등 비전문 일상 용역. 전문자격이 필요한 일은 등록 차단.

**5. 전자 용역 합의서**
매칭 시 근로 합의서(US-13)가 아니라 **전자 용역 합의서**를 노출한다 — "도급(일의 완성), 근로계약 아님" 명시.

---

## 상세 시나리오 (Detailed Scenarios)

### 시나리오 1: 정상 플로우

1. 개인 의뢰자가 "원룸 청소 2시간, 3만원" 용역을 등록한다.
2. 비전문 카테고리·도급계약으로 분류된다.
3. 매칭된 수행자에게 전자 용역 합의서가 노출된다.
4. 양측 동의 → 용역 계약 성립.

### 시나리오 2: 대체 플로우

* 사업주도 용역 의뢰 가능 (예: 소상공인의 일회성 잡무).
* 운반-부수 심부름은 A등급, 배송-목적은 운송수단에 따라 분류 (`Job_Category_Legal_Matrix.md` §4.1).

### 시나리오 3: 에러 처리

* 전문자격 필요 직무(요양·의료 등) 등록 시도: 차단, "전문 자격 필요 직무는 용역 트랙 불가" 안내.

### 시나리오 4: 엣지 케이스

* 반복·정기 의뢰: 도급으로 위장한 실질 근로(위장도급) 위험 → 반복 패턴 감지 시 고용형 트랙으로 안내.

## Business Rules

* **정책**: 용역 트랙은 비전문·일회성 일감만. 반복·종속적이면 고용형으로 유도 (위장도급 방지).
* **계약**: 도급계약. 근로기준법 적용 대상 아님을 합의서에 명시.
* **검증**: 전문자격 필요 직무는 용역 트랙에서 차단.
* **법적**: 플랫폼은 용역 중개자. 운반-목적 일감은 운송수단 분류를 따른다.

## Acceptance Criteria

- [x] 사업자등록 없는 개인이 의뢰자로 용역을 등록할 수 있다 (`requesterType: "individual"`)
- [x] 의뢰자 유형(개인/사업주)과 계약 유형(고용/용역)이 구분된다 (`ContractType = "employment" | "service"`)
- [x] 용역 의뢰는 건당 보수의 도급계약으로 등록된다 (`fee` 건당, `service-requests.json` 120건)
- [x] 비전문 카테고리만 허용된다 (7종: errand/homecleaning/assembly/moving/pet/queue/walkdelivery)
- [x] `/sim/service` 목록에 도급(근로계약 아님) 안내 배너가 노출된다
- [x] 전자 용역 합의서 모달 — 도급계약·근로계약 아님·건당 보수 명시 (US-13 근로 합의서와 분기)
- [x] 반복·정기 패턴(의뢰자×카테고리 3건 이상) 감지 → 고용형 트랙 전환 안내

## 의존성 및 제약사항

* **선행**: 데이터 모델에 `requesterType`(business/individual), `contractType`(employment/service) 추가
* **관련**: US-13(근로 합의서)과 분기 — 용역은 용역 합의서
* **제약**: 플랫폼의 용역 중개가 어떤 등록(직업소개업·통신판매중개 등)에 해당하는지 법무 검토 필요
