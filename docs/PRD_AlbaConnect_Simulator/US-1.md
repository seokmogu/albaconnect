# US-1: 구인자는 자기 매장 매칭 현황만 보기 위해 본인 시점 마이페이지에 진입할 수 있다

**Epic**: Epic 1 - 마이페이지

**Phase**: Phase 1

**Priority**: P0

**구현 상태**: 미구현 (`/sim/me/employer/[id]`)

---

## 배경 및 해결하고자 하는 문제

현재 시뮬레이터의 구인자 화면(`/sim/employer/[id]`)은 관리자가 312개 사업장 목록에서 임의 사업장을 골라 들여다보는 구조다. 실제 서비스에서 사장님은 "내 매장"의 매칭 현황만 보면 되는데, 시뮬에서는 본인 시점 진입점이 없어 사용 경험을 검증할 수 없다.

사장님의 핵심 관심사는 불안 해소다. "지금 내가 올린 공고가 매칭되고 있는가, 어떤 워커가 오는가, 그 워커는 믿을 만한가"를 한 화면에서 확인하고 싶어 한다. 관리자 시점 화면은 이 정서적 맥락을 담지 못한다.

이 스토리는 구인자가 본인 컨텍스트로 고정된 마이페이지에 진입해, 자기 매장 공고와 매칭 결과만 집중해서 보도록 한다.

---

## 기능 요구사항 (Functional Requirements)

### 세부 기능

**1. 본인 시점 진입**
구인자는 본인 사업장 ID로 마이페이지에 진입하며, 진입 후 화면은 해당 사업장 컨텍스트로 고정된다. 다른 사업장 데이터는 노출하지 않는다.

**2. 내 공고 진행상황**
본인 매장의 모든 공고를 진행 상태(dispatch 전 / 워커 응답 대기 / 매칭 확정)별로 구분해 표시한다.

**3. 매칭 워커 정보**
매칭이 확정된 공고는 매칭된 워커의 이름·평점·신뢰도와 함께, 워커가 수락한 사유와 수락까지 걸린 시간을 표시한다.

**4. 매장 KPI**
활성 공고 수, dispatch 횟수, 매칭 확정 건수, 월 인건비 예산을 요약 카드로 제공한다.

---

## 상세 시나리오 (Detailed Scenarios)

### 시나리오 1: 정상 플로우 (Happy Path)

1. 사장님이 본인 사업장 ID로 마이페이지에 진입한다.
2. 화면 상단에 매장명·위치·평점·KPI 카드가 표시된다.
3. 진행 중 공고 목록에서 각 공고의 상태 배지(매칭 확정/응답 대기)를 확인한다.
4. 매칭 확정 공고를 보면 매칭 워커 정보와 수락 사유가 인용구로 표시된다.

### 시나리오 2: 대체 플로우 (Alternative Flows)

* 매칭이 아직 안 된 공고: 상태 배지가 "응답 대기" 또는 "dispatch 전"으로 표시되고 워커 정보 영역은 비어 있다.
* 공고가 하나도 없는 사업장: "등록된 공고가 없습니다" 안내를 표시한다.

### 시나리오 3: 에러 처리 (Error Handling)

* 존재하지 않는 사업장 ID로 진입: 404 처리한다.
* 시뮬 데이터 파일이 없을 때: 빈 상태 안내를 표시하고 화면은 깨지지 않는다.

### 시나리오 4: 엣지 케이스 (Edge Cases)

* 공고는 많은데 매칭이 0건인 사업장: KPI에 매칭 0으로 표시, 매칭 현황 안내는 "아직 매칭된 공고가 없습니다".

## Business Rules

* **정책**: 마이페이지는 본인 사업장 데이터만 노출한다. 다른 사업장으로의 이동 링크를 제공하지 않는다.
* **검증**: 진입 ID가 실재하는 사업장인지 확인한다.
* **UX 보호**: 매칭 워커 정보는 평점·신뢰도 등 신뢰 시그널을 우선 배치한다.
* **엣지 케이스**: 데이터 부재 시에도 화면 골격은 유지한다.

---

## Acceptance Criteria

- [ ] 구인자가 본인 사업장 ID로 마이페이지에 진입할 수 있다
- [ ] 화면이 해당 사업장 컨텍스트로 고정되고 다른 사업장 데이터는 노출되지 않는다
- [ ] 내 공고가 상태별(매칭 확정/응답 대기/dispatch 전)로 구분 표시된다
- [ ] 매칭 확정 공고에 워커 평점·신뢰도·수락 사유·수락 시간이 표시된다
- [ ] 매장 KPI(활성 공고/dispatch/매칭 확정/예산)가 표시된다
- [ ] 존재하지 않는 사업장 ID는 404로 처리된다

---

## 성공 지표 (Success Metrics)

* 본인 시점 진입 성공률 100%
* 매칭 워커 정보에 수락 사유 노출률 100%
* 마이페이지 첫 렌더 1초 이내
