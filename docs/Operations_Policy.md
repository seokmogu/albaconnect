## 1. 근로시간 기록 — 양측 동의 가능한 방식

원칙: **한쪽이 일방 기록하면 안 된다. 양측이 신뢰하는 객관적 신호를 쓴다.**

| 방식 | 역할 |
|------|------|
| 지오펜스 체크인 | 워커가 매장 반경 안에 있을 때만 체크인 가능 — 위치 위조 차단 (코드: `geofence_checkin`) |
| 양방향 확인 | 워커 체크인 → 사장님 폰 알림 → 사장님 1탭 승인. 퇴근도 동일 |
| 분 단위 자동 기록 | 사후 주장이 아니라 그 순간 타임스탬프 + 양측 실시간 노출 |
| QR/NFC 보조 | 매장 QR 스캔 — 물리적 현장 확인 |

→ 분쟁의 대부분은 "지오펜스 체크인 + 사장님 양방향 확인" 타임스탬프로 해소.

## 2. 긱(건당) 노동 — 완료 증명

시간제와 달리 작업 단위라 시간 기록만으로 부족하다.

- **작업 정의**: 공고에 할 일을 명시 (예: 전단지 500장 배포, 테이블 20개 세팅)
- **결과물 사진**: 작업 전/후 사진 업로드
- **사장님 승인 게이트**: 워커 "완료" → 사장님 확인 → 정산. **사장님 무응답 시 N시간 후 자동 승인** (사장님이 일부러 확인을 미뤄 정산을 지연하는 것 차단)
- **체크포인트**: 긴 작업은 시작/중간/종료 3회 체크인

## 3. 계약 동의 — 전자 근로 합의서

> ⚠️ 법적 의무 대응. 초단기·건당도 근로계약서 작성 의무가 있다 (`Legal_Considerations.md` §1.1).

### 흐름

```
매칭 확정 → 전자 근로 합의서 생성 → 양측에게 동시 노출 → 양측 "동의" → 계약 성립 기록
```

### 합의서 필수 항목

- 사업장명 / 워커명
- 근무 일시·시간 (시작·종료)
- 근무 장소
- 업무 내용 (긱은 작업 정의 포함)
- 시급 / 총 지급액 / 정산 방식 (토스 에스크로)
- 고용형태 (긱·일일·단기·장기)
- 취소·노쇼 규정 요약
- 플랫폼 지위 명시: "알바몬 커넥트는 중개자이며 근로계약 당사자는 사업주와 워커"

### 규칙

- 양측이 모두 동의해야 매칭이 최종 확정된다 (한쪽만 동의 시 보류)
- 동의 시각·내용을 변경 불가 기록으로 보관 → 분쟁 시 근거
- 합의서 미동의 상태로는 체크인 불가

## 4. 노쇼·불량 노동 — "책임 전가가 아니라 4단 분산"

> 양면 시장에서 한쪽에 100% 책임을 지우면 그쪽이 이탈한다. 답은 4단 분산이다.

```
예방  →  즉시 대응  →  분쟁 해결  →  최후 흡수
```

### 4.1 워커 노쇼

- **예방**: 신뢰도 점수 (노쇼 이력 → 매칭 페널티)
- **즉시 대응**: 차순위 워커 자동 재디스패치 (사장님 손실 최소화, 재디스패치 무료)
- **책임**: 워커 신뢰도 하락, 반복 시 매칭 정지

### 4.2 사장님 노쇼·부당 (워커가 갔는데 일이 없거나 임금 후려치기)

- 워커 체크인 기록이 있으면 **도착 보장** (예: 일 취소 시 1~2시간분 보장)
- 에스크로에 금액이 예치돼 있어 사장님이 "안 줄" 수 없음

### 4.3 불량 노동 (가장 모호)

- **사전 정의**: 공고의 작업 기준 ↔ 분쟁 시 대조
- **에스크로 보류 + 트리아지**: 사장님 "불량" 신고 → 정산 보류 → `DisputeTriageAgent` 1차 분류 → 운영팀 검토 → 부분/전액/기각
- **양방향 평점**: 사후 평판 자정

### 4.4 최후 흡수 — 플랫폼 분쟁 준비금

- 명백한 과실은 그 당사자 부담
- 모호한 케이스는 플랫폼이 **분쟁 준비금**으로 흡수
- 재원: take rate의 일부를 분쟁 준비금으로 적립
- 효과: 양측 모두 "플랫폼이 받쳐준다"는 신뢰 → 시장 유지
