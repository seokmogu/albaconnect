## 1. 근로기준법 적용

### 1.1 핵심 — 초단기·건당도 근로기준법 적용

| 오해 | 실제 (AI 추정) |
|------|---------------|
| 건당·1일 알바라 근로계약서 불필요 | 단시간·초단기도 근로계약서 작성 의무. 미작성 시 과태료 |
| 초단기라 최저임금 예외 | 최저임금 그대로 적용 |
| 주휴수당·4대보험 회피 | 주 15시간 미만 시 주휴수당 면제 가능, 4대보험은 요건 차이. 단 근로자성 인정 시 적용 |

→ 전자 근로 합의서(계약 동의 기능)는 **선택이 아니라 법적 의무 대응**이다.

### 1.2 플랫폼의 사용자성 리스크

- 근로계약 당사자: **사장님(사용자) ↔ 워커**. 플랫폼은 원칙적으로 중개자.
- 위험: 플랫폼이 업무 지시·평가·디스패치를 강하게 통제하면 "실질적 사용자"로 간주될 수 있음 (플랫폼 노동 판례 흐름).
- 완화책:
  - 플랫폼은 "추천·매칭"에 머물고 강제 배차를 하지 않음
  - 약관에 "플랫폼은 중개자, 근로계약 당사자는 사장님과 워커" 명시
  - 평점·신뢰도는 매칭 참고용이며 근로 지휘·감독이 아님을 분명히

## 2. 유상운송 — 별개 법 영역 (delivery 카테고리)

> ⚠️ delivery(퀵·배달) 카테고리는 카페·식당 알바와 **법적 성격이 근본적으로 다르다.**

| 쟁점 | 내용 (AI 추정) |
|------|---------------|
| 자가용 유상운송 | 자가용 차량으로 돈 받고 운송 = 여객/화물자동차 운수사업법 위반 |
| 퀵·이륜차 배송 | 화물자동차 운수사업법 / 생활물류서비스산업발전법(2021) 적용 |
| 운송 주선 | 플랫폼이 운송을 주선하면 화물운송주선사업 등록 필요 가능성 |
| 보험 공백 | 유상운송 전용(영업용) 보험 없이 사고 시 보상 공백 |

→ **권고**: MVP에서 `delivery` 카테고리 제외, 또는 생활물류법 준수 인증 파트너를 통한 별도 트랙으로만 운영. 일반 알바 매칭 플랫폼이 퀵서비스를 그대로 매칭하면 무허가 운송 주선 소지.

## 3. 플랫폼 노동자 보호 입법 트렌드

- 특수고용직(특고) 산재보험 적용 확대
- 플랫폼 종사자 보호 관련 입법 논의 진행 중
- 알고리즘 투명성·표준계약서 요구 흐름

→ 정책 변화를 모니터링하고, 산재·상해 보험 패키지(GTM 문서 워커 부가가치)를 선제 설계.

---

## 4. 카테고리별 법적 트랙 분리

| 카테고리 | 법적 트랙 | MVP 포함 |
|----------|----------|:---:|
| cafe / restaurant / retail / event / cleaning / manufacturing / other | 일반 근로 (근로기준법) | ✅ |
| **delivery** | 유상운송 (운수사업법 / 생활물류법) — 별도 인증 필요 | ⚠️ 보류 |

→ 시뮬레이터 데이터·UI에서 delivery 공고에 "법적 검토 필요" 플래그를 둔다.

---

## 5. 출시 전 법무 게이트 체크리스트

- [ ] 전자 근로 합의서 양식 노무사 검토
- [ ] 플랫폼 약관(중개자 지위, 면책) 법무 검토
- [ ] delivery 카테고리 운수/물류법 검토 — 포함 여부 결정
- [ ] 에스크로·정산의 자금이체업 해당 여부 검토 (전자금융거래법)
- [ ] 개인정보(위치·이력서) 처리방침 — 위치정보법 포함
- [ ] 알고리즘 통제 강도 ↔ 사용자성 리스크 검토
- [ ] 분쟁 처리·보상(분쟁 준비금)의 약관 근거 검토
